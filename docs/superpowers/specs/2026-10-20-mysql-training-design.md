# 离线 MySQL 培训工具：第一版产品设计

日期：2026-10-20

状态：用户于 2026-10-20 确认整体设计，包含第 3 节建议默认值。正在制定实施计划，尚未进入产品代码开发。

## 1. 目标与使用场景

面向刚接触数据库的学员，提供每台电脑独立运行、完全离线的 MySQL 查询培训工具。学员无需自行配置数据库，通过讲解、示例、练习、结果反馈和自由探索，逐步掌握常用查询。

成功标准：断网环境下可启动并进入课程；SQL 在真实 MySQL 中执行；学习进度和草稿可在重新启动后恢复；新手能从报错和分层提示中获得下一步方向。

## 2. 已由用户确认的决定

- 单机独立使用，第一版只做 MySQL，Hive 留待后续。
- 使用真实 MySQL，便携式打包、一键启动、一键恢复练习数据。
- 查询分析优先，不做建库建表、插入、更新和删除的教学。
- 采用电商订单业务数据。
- 采用先讲解、看示例、独立练习、分层提示、总结的教学方式。
- 学习页面采用左侧课程导航、中间任务及 SQL 编辑与结果区、右侧数据参考的布局。
- 运行 SQL 和提交判题分开；支持不同的正确写法。
- 本地学员档案仅输入姓名或昵称进入，不设置密码。
- 首页提供继续学习、课程目录、自由实验室和学习记录。
- 章节推荐按顺序学习，允许自由选择，不强制解锁。
- 自动保存草稿；记录独立完成或参考答案后完成；不做排行榜和计时压力。
- 自由实验室只开放查询；恢复练习数据和重置学习进度分别处理。

## 3. 已随整体设计确认的默认值

- 第一版面向 Windows 10/11 64 位电脑，采用本地服务加浏览器页面。
- 分发包包含 MySQL 和工具运行所需组件；首次使用不联网下载依赖。
- 优先设计为解压到可写目录后启动，不要求学员手动安装系统服务。
- 题库目标约 40 题、8 章；数据为固定的模拟数据，覆盖必要的边界情况。
- 学习数据保存在工具的数据目录；重新启动后保留。跨电脑同步及独立导出备份不纳入第一版。
- MySQL 具体版本、发行文件及运行依赖在实施方案中选定并验证，包体积和最低资源需求以实际打包测试结果为准。

## 4. 使用流程与页面

### 启动与学员档案

启动器检查目录可写性、所需组件和端口，初始化或启动工具自带 MySQL，再打开本地学习页面。页面在准备期间显示明确状态，启动失败时提供可理解的原因和重试入口。

首次输入姓名或昵称创建学员档案；之后默认进入上次档案，可切换或新建。同名输入提示选择已有档案或使用其他昵称。档案通过内部唯一编号关联学习记录，昵称不是数据库账号。

### 首页

继续学习是主要入口，回到上次章节、题目和草稿。课程目录展示完成状态；自由实验室和学习记录提供次级入口。切换学员不混用学习进度。

### 学习工作台

- 左侧：章节、题目、完成状态。
- 中间上方：简短知识讲解、可运行示例和当前业务问题。
- 中间下方：SQL 编辑器、运行、提交判题、结果表及反馈。
- 右侧：表结构、字段中文说明、样例数据和表关系。

讲解和示例与练习区分，示例不会覆盖已有草稿。新题可提供必要的起始语句；执行错误后保留输入。切题和关闭前保存，编辑期间自动保存。题目及实验室草稿按学员隔离。

提示依次提供思路、语法结构、参考答案，由学员主动打开。查看普通提示不等于查看答案。首次通过记录完成方式；再次独立完成可另外记录，保留曾查看答案的事实。

### 自由实验室

沿用编辑器、数据参考和结果区，移除题目判题。支持自由查询、查询历史、命名保存和重新打开 SQL。历史按学员保存，重复运行不应使界面难以使用。

### 学习记录

展示章节进度、题目完成状态、参考答案使用情况及已保存 SQL；能够返回对应题目。第一版不做成绩排名、学习时长考核或教师管理。

## 5. 课程范围

| 章节 | 内容 |
| --- | --- |
| 认识数据库 | 表、行、列、字段类型、主键、查看表结构 |
| 基础查询 | SELECT、字段选择、别名、DISTINCT |
| 条件筛选 | WHERE、比较运算、AND/OR、IN、BETWEEN、LIKE、IS NULL |
| 排序与截取 | ORDER BY、多字段排序、LIMIT |
| 分组统计 | COUNT、SUM、AVG、MAX、MIN、GROUP BY、HAVING |
| 多表关联 | INNER JOIN、LEFT JOIN、关联条件、重复行 |
| 查询进阶 | 基础子查询、CASE WHEN |
| 综合练习 | 多知识点组合的电商分析任务 |

每题定义题目目标、字段说明、输出要求、知识点、分层提示、参考 SQL 和判题规则。第一版不包含窗口函数、存储过程、数据库运维及复杂性能优化。

## 6. 电商数据与口径

采用客户、商品、订单、订单明细、商品分类五张表。客户与订单、订单与明细、商品与明细、分类与商品建立清晰关系。

固定数据包括未下单客户、未售出商品、可空字段、同名客户、取消订单，以及多条明细等场景。基础题保持简单，后续题逐步使用边界数据。

销售额按订单明细的数量乘成交单价计算，金额使用精确数值类型。题目明确时间范围、取消订单是否排除、金额精度和输出字段。日期题使用固定日期条件，避免随系统日期变化导致答案漂移。

## 7. 执行与判题

所有练习在随包提供的真实 MySQL 上执行，固定版本及关键 SQL 配置，避免不同电脑规则不一致。工具自带实例使用专用目录和端口，不修改电脑上已有的数据库。

学员查询通过仅具备练习数据读取权限的数据库账号执行。管理初始化和恢复所需权限不暴露给编辑区。后端只接受支持范围内的单条查询，包括课程所需的子查询；拒绝修改数据、多语句以及文件读写等越界操作。权限控制和语句检查共同约束查询。

运行返回结果或错误；提交时重新执行当前 SQL 并判题。判题比较结果，不按 SQL 字符串匹配：

- 检查要求的输出列；仅在题目明确要求时检查列别名。
- 默认忽略行顺序，但保留重复行的数量；要求排序的题目检查顺序。
- 排序及前 N 条题目给出明确的并列处理规则，参考查询采用足够的排序条件。
- NULL 与空字符串区分；数值按类型和题目精度规范比较，避免显示格式导致误判。
- 题目明确要求某种语法时，额外使用结构检查；不靠关键词是否出现判断掌握情况。

执行失败展示原始 MySQL 报错，并为常见错误补充经过整理的中文说明；未知错误保留原文，不伪造解释。答案不对时先提示列、行数、值或排序的差异，不直接展示完整标准结果。

限制单次查询时间及界面展示行数，防止错误关联卡住页面；展示截断与完整判题分开，不能仅比较预览的前几行。超过判题资源限额时明确提示无法完成判定，不判为正确。

## 8. 组件职责与数据流

- 启动与生命周期模块：负责目录检查、数据库初始化、端口选择、启动状态、关闭及异常重启恢复。
- 本地应用服务：提供学员、课程、进度、草稿、历史及保存查询的接口；仅监听本机。
- 查询执行模块：验证查询范围、执行只读查询、限制资源、返回结构化结果及错误。
- 判题模块：读取题目规则，执行并比较答案，输出可解释反馈。
- 内容与种子数据：保存版本化的课程、题目、提示、参考答案、表说明和固定数据。
- 浏览器界面：组织学习流程和结果展示，不直接持有数据库管理权限。

主要数据流：选择题目 → 读取内容与草稿 → 编辑 SQL → 执行模块运行 → 展示结果；提交时进入判题模块 → 返回反馈 → 保存学习记录。

学习元数据与可恢复的练习数据分开管理。关闭页面不会丢弃已保存记录；提供明确的退出工具入口以停止工具拥有的进程，不能停止电脑上其他 MySQL 实例。

## 9. 恢复与异常处理

恢复练习数据需要用户明确确认，只重建工具自己的练习数据，不删除学员、进度、草稿或历史。重置学习进度单独提供并说明影响范围。

初始化被中断、端口占用、目录无写入权限、数据库启动失败时给出具体提示。启动器只管理自身实例，不通过结束所有数据库进程解决问题。

不提供在线 AI 辅导。讲解、提示和常见错误说明预先内置，断网时全部可用。

## 10. 验收与验证

- 在未预装 MySQL 的目标 Windows 环境断网验证启动、首次初始化、关闭和再次打开。
- 在已有 MySQL 的电脑上验证实例隔离及端口冲突处理。
- 按课程逐题验证参考答案、提示、口径及结果；验证不同正确 SQL 写法可以通过。
- 对重复行、NULL、排序并列、空结果、精确金额和结果截断进行判题验证。
- 验证写入语句、多语句及越界查询被拒绝；超时可恢复，页面继续可用。
- 验证切题、切换学员和重新启动后，草稿及进度正确恢复。
- 验证恢复练习数据保留学习记录；单独重置进度的范围符合说明。
- 人工检查中文内容、编辑区、结果表和小屏幕下的布局可用性。
