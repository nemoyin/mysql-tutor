# 第一版验收记录

本记录区分已运行的验证与尚未具备环境的验证，不把开发机测试等同于干净系统验收。

## 当前已验证

- Python 3.12.14、MySQL 8.4.11 Windows x64；官方 HTTPS 下载文件的 SHA-256 固定在 runtime/manifest.json。
- 工程健康接口、目录约束、端口冲突、中文及空格路径兼容、真实 MySQL 启动与重启。
- 固定电商数据：30 客户、6 分类、40 商品、120 订单、300 明细。订单 1 的明细金额合计 79.80。
- 只读数据库账号及 SQL 支持范围检查、查询超时后继续执行、200 行预览截断、中文与原始报错。
- 结果判题：保留重复行数量、NULL、金额精度、排序与等价写法；截断不能误判通过。
- 8 章 40 题的全部参考答案通过，针对性错误写法不通过，至少 10 个等价查询通过。
- 学员隔离、草稿版本冲突、本地持久化、参考答案使用记录、学习进度与数据恢复的边界。
- 浏览器完整流程：建档、运行查询但不提交、提交通过、刷新恢复草稿、进入自由实验室运行查询。
- 真实浏览器截图见 screenshots/home.png 和 screenshots/workspace.png；实验室编辑区遮挡操作按钮问题已有回归修复。

## 环境限制

当前可用环境为开发 Windows 主机，未提供独立的干净 Windows 10 和 Windows 11 虚拟机。因此“在没有任何预装依赖的两种干净系统上运行”和跨硬件最低配置尚未完成验证；提供便携包及验收脚本继续复验。首包不承诺特定启动时间或最低内存。
