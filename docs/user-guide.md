# SQL 学习工坊 · 使用说明

适用：Windows 10/11 64 位电脑。工具自带 MySQL，无需另外安装 Python、Node.js 或 MySQL；需要电脑上有现代浏览器。

## 开始使用

1. 将整个 ZIP 解压到有写入权限的本地文件夹。不要直接在压缩包中运行，也不要只复制其中的 exe。
2. 双击 `MySQL学习工具.exe`。浏览器会自动打开本机学习页面；首次启动需要初始化数据库，请等待页面显示 MySQL 已就绪。
3. 输入姓名或昵称创建本地档案。不需要密码，同一台电脑可以保存多个学员档案。
4. 点击“开始学习”，也可从首页直接选择任意章节。

## 学习与练习

- 课程共 8 章 40 题：认识数据库、基础查询、条件筛选、排序与截取、分组统计、多表关联、查询进阶、综合练习。
- 点击“知识讲解与示例”查看讲解。运行示例会单独显示结果，不覆盖你的草稿。
- 在 SQL 编辑器中输入语句。点击“运行 SQL”观察结果；点击“提交判题”检查是否完成题目，两者互相独立。
- 需要帮助时依次打开两层提示。查看参考答案会记录使用情况，不会阻止继续练习。
- 右侧表结构解释英文表名、字段及关联关系；点击“查看前 10 行数据”浏览样例。
- 查询区只允许读取练习数据，不能执行插入、更新、删除和建表。长时间运行或结果过大的查询会被限制。
- 运行结果最多展示 200 行，判题独立处理结果，超过判题限制会明确提示，不能把截断的结果当作通过。

## 自由实验室与学习记录

自由实验室使用同一套电商数据，无题目限制。可以命名保存 SQL，在“学习记录 → 已保存 SQL”重新打开。查询历史保留每位学员最近 1000 次操作，分页显示。

草稿在编辑后自动保存；切换页面前会等待保存。请留意“已自动保存”状态。异常关闭时若发现本机未保存副本，页面提供恢复入口。多标签同时编辑同一道题发生版本冲突时，会提示重新加载，并保留本机副本供恢复。

## 数据与退出

- 学员档案、进度、草稿和历史存放在工具目录的 `data/`，不会上传。
- “工具设置 → 恢复练习数据”只重新准备电商数据，保留学习记录。
- “工具设置 → 重置我的学习进度”仅清除当前学员的完成状态、参考答案记录和继续学习位置；保留草稿、查询历史与命名保存的 SQL。
- “工具设置 → 退出工具”保存草稿并关闭本工具的数据库。只关闭浏览器标签页不会退出后台工具。
- 移动工具前先退出，然后复制整个文件夹并保留 `data/`。第一版不提供云同步和跨电脑账户。

## 常见情况

- 首次启动失败：检查 `data/logs/` 下的日志，并确认完整解压、目录可写。
- 中文路径：工具会在系统临时目录建立兼容映射，实际数据仍保存在工具文件夹。如果系统临时目录也包含非英文字符，按提示改为纯英文解压目录。
- 显示工具已运行：使用已打开的学习页面，或先从该页面退出工具再重新启动。
- 页面未自动打开：在任务管理器确认工具仍在运行。维护人员可通过启动参数指定端口，默认首先尝试 `http://127.0.0.1:18765`，占用时自动选择其他端口。
- 本机已有 MySQL：工具使用独立进程、目录和端口，不更改已有数据库。

学习记录属于本地培训档案，无密码保护，适合个人练习或可信的共用电脑，不作为身份认证或正式考试凭证。
